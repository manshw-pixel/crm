# QA Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/qa-run [feature]` drives the live CRM in a dedicated QA org through scripted Playwright scenarios, then Claude analyses failures and publishes a report page.

**Architecture:** A Node runner in `tests/qa/` (pure, unit-tested core + thin Playwright layer) writes `results.json` and screenshots. A report renderer turns results + history into one HTML file. A Claude slash command runs the runner, adds cause/fix analysis to each failure, renders, and publishes to one fixed artifact URL.

**Tech Stack:** Node 20 ESM, Playwright (already in `tests/node_modules`, used by `tests/health`), `node:test` for runner unit tests, plain HTML/CSS report.

**Spec:** `docs/superpowers/specs/2026-10-14-qa-agent-design.md`

## Global Constraints

- No Supabase access of any kind: no service-role key, no `@supabase/supabase-js` import, no SQL. Everything through the app UI at `QA_BASE_URL`.
- Every scenario runs only after the org guard passes; mismatch aborts the WHOLE run (exit code 2), never a warning.
- The agent never edits `src/` or opens PRs; analysis is text in the report only.
- Credentials only in `.env.qa` at repo root, git-ignored. Never logged, never written to `results.json` or the report.
- Live-site retry: one automatic retry per scenario; pass-on-retry is status `"flaky"`, not `"pass"`.
- Any test that changes org limits restores the original value in a `finally`.
- Additive only: no changes to `src/`, `build.mjs`, `tests/health`, `tests/rls`, CI workflows.
- Run IDs: `qa-YYYYMMDD-HHMM` (local time). Every record a run creates has the run ID in its name, e.g. account `QA qa-20261014-1530 Acme`.

## Review Focus

1. **Signed in to the wrong org** (QA creds pointed at a real org by mistake) → run refuses before any click that writes. Test: Task 3 guard unit test + Task 12 live refusal check.
2. **Sidebar org name still "…"** (org not yet loaded) → guard waits up to 15s for a real name, then fails closed; it must never treat "…" or "" as a match. Test: Task 3 `readOrgName` unit test.
3. **Deployed build behind master** (Pages deploy still running) → pre-flight reports "live is <sha>, master is <sha>, wait for deploy" and exits 3 without running scenarios. Test: Task 3 `checkVersion` unit test.
4. **Invoices cannot be deleted in the UI** (no delete action in `src/14-invoices.jsx`/`27-invoice-form.jsx`) → finance and dashboard assertions must be scoped to this run's tagged accounts or be before/after deltas, never absolute org totals. Test: Task 9 scenarios assert deltas; reviewer rejects any absolute-total assertion.
5. **Crashed previous run left data** → reset deletes every account whose name starts with `QA qa-` before seeding. Test: Task 4 `staleAccountNames` unit test.

```js
// Loads the QA agent's credentials. These are real logins for the live site, so this
// module is the only place that reads them and nothing downstream may log them.
import { readFileSync, existsSync } from "node:fs";

const ROLES = ["admin", "csm", "am", "lead"];
const KEYS = ["QA_BASE_URL", "QA_ORG_NAME", ...ROLES.flatMap(r => [`QA_${r.toUpperCase()}_EMAIL`, `QA_${r.toUpperCase()}_PASS`])];

export function parseEnv(text) {
  const out = {};
  for (const line of text.split(/\r?\n/)) {
    if (!line.trim() || line.trim().startsWith("#")) continue;
    const i = line.indexOf("=");
    if (i > 0) out[line.slice(0, i).trim()] = line.slice(i + 1).trim();
  }
  return out;
}

export function validateEnv(e) {
  const missing = KEYS.filter(k => !e[k]);
  if (missing.length) throw new Error(`.env.qa is missing ${missing.join(", ")} -- see .env.qa.example`);
  const users = Object.fromEntries(ROLES.map(r => [r, { email: e[`QA_${r.toUpperCase()}_EMAIL`], pass: e[`QA_${r.toUpperCase()}_PASS`] }]));
  return { baseUrl: e.QA_BASE_URL, orgName: e.QA_ORG_NAME, users };
}

export function loadQaEnv(path = ".env.qa") {
  if (!existsSync(path)) throw new Error(`${path} not found -- copy .env.qa.example and fill in the QA logins`);
  return validateEnv(parseEnv(readFileSync(path, "utf8")));
}
```

```js
// Pure runner core: no browser, no network. run.mjs supplies makeCtx (which opens pages)
// and onFail (which takes screenshots); everything here is unit-tested in isolation.
export class GuardError extends Error {}

const pad = n => String(n).padStart(2, "0");
export const makeRunId = (d = new Date()) =>
  `qa-${d.getFullYear()}${pad(d.getMonth() + 1)}${pad(d.getDate())}-${pad(d.getHours())}${pad(d.getMinutes())}`;

export async function runScenarios(scenarios, makeCtx, { onFail } = {}) {
  const results = [];
  for (const s of scenarios) {
    const t0 = Date.now();
    let lastErr, artifacts;
    for (let attempt = 1; attempt <= 2; attempt++) {
      let ctx;
      try {
        ctx = await makeCtx(s);
        await s.run(ctx);
        results.push({ id: s.id, feature: s.feature, title: s.title, status: attempt === 1 ? "pass" : "flaky", attempts: attempt, ms: Date.now() - t0 });
        lastErr = null;
        break;
      } catch (err) {
        if (err instanceof GuardError) throw err;
        lastErr = err;
        if (attempt === 2 && onFail) artifacts = await onFail(s, ctx, err, attempt).catch(() => undefined);
      } finally {
        await ctx?.close?.().catch(() => {});
      }
    }
    if (lastErr) results.push({ id: s.id, feature: s.feature, title: s.title, status: "fail", attempts: 2, ms: Date.now() - t0, error: String(lastErr.message || lastErr), artifacts });
  }
  return results;
}

export function summarise(results) {
  const byFeature = {};
  for (const r of results) {
    const f = (byFeature[r.feature] ??= { pass: 0, fail: 0, flaky: 0 });
    f[r.status]++;
  }
  const count = s => results.filter(r => r.status === s).length;
  return { total: results.length, pass: count("pass"), fail: count("fail"), flaky: count("flaky"), byFeature };
}
```

Note: `onFail` runs in the second attempt's `catch`, BEFORE `finally` closes ctx, so the page is still open for the screenshot.

```js
// The only thing standing between the QA agent and real client data. Fail closed:
// anything other than an exact, loaded org name is a GuardError, which stops the run.
import { GuardError } from "./core.mjs";

export function parseOrgName(text) {
  const i = text.lastIndexOf("· ");
  if (i < 0) return null;
  const name = text.slice(i + 2).trim();
  return !name || name === "…" ? null : name;
}

export function assertQaOrg(actual, expected) {
  if (actual !== expected) throw new GuardError(`org guard: signed in to "${actual ?? "(not loaded)"}", expected "${expected}". Run aborted before any change.`);
}

export const parseLiveVersion = html => html.match(/const APP_VERSION = "([0-9a-f]{7,40})"/)?.[1] ?? null;

export const checkVersion = (live, master) => live === master
  ? { ok: true, message: `live build ${live} matches master` }
  : { ok: false, message: `live is ${live ?? "unknown"}, master is ${master}: wait for the Pages deploy to finish, then re-run` };
```

```js
export async function signIn(browser, env, role, { viewport } = {}) {
  const context = await browser.newContext(viewport ? { viewport } : {});
  const page = await context.newPage();
  const close = () => context.close();
  try {
    await page.goto(env.baseUrl);
    await page.fill('input[type="email"]', env.users[role].email);
    await page.fill('input[type="password"]', env.users[role].pass);
    await page.getByRole("button", { name: /sign in/i }).click();
    const name = await waitForOrgName(page);
    assertQaOrg(name, env.orgName);
    return { page, context, close, role, env };
  } catch (e) { await close(); throw e; }
}

// Polls the sidebar for up to 15s; a name still "…" at the end is a guard failure, not a pass.
async function waitForOrgName(page) {
  const until = Date.now() + 15000;
  while (Date.now() < until) {
    const text = await page.locator("text=/· /").first().textContent({ timeout: 2000 }).catch(() => "");
    const name = parseOrgName(text || "");
    if (name) return name;
    await page.waitForTimeout(500);
  }
  return null;
}

export async function signOut(page) {
  await page.getByRole("button", { name: /^sign out$/i }).first().click();
}
```

```js
import { readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";

const CSV = readFileSync(fileURLToPath(new URL("./fixtures/accounts.csv", import.meta.url)), "utf8");

export const fixtureCsv = (runId, owners) =>
  CSV.replaceAll("{RUN}", runId).replaceAll("{CSM}", owners.csm).replaceAll("{AM}", owners.am);

export const staleAccountNames = (names, runId) =>

// Upload through the real import UI (src/17-csv.jsx). Uses an in-memory file so nothing
// touches disk. Confirm the import button label and the confirm step in 17-csv.jsx.
export async function importCsv(page, csvText, filename = "qa.csv") {
  await page.getByRole("button", { name: /import/i }).first().click();
  await page.locator('input[type="file"]').setInputFiles({ name: filename, mimeType: "text/csv", buffer: Buffer.from(csvText) });
  await page.getByRole("button", { name: /^(import|confirm)/i }).last().click();
  await page.getByText(/imported|added|updated/i).first().waitFor({ timeout: 20000 });
}

// Deletes stale QA accounts via the Accounts page's bulk select + BULK_DELETE
// (src/19-dialogs-bulk.jsx, src/20-account-list.jsx), then imports the fixture.
export async function resetQaOrg(ctx, runId) {
  const { page, env } = ctx;
  await page.getByRole("link", { name: /accounts/i }).or(page.getByRole("button", { name: /^accounts$/i })).first().click();
  await page.getByPlaceholder(/search/i).first().fill("QA qa-");
  const names = await page.locator("[data-account-name]").allTextContents();
  const stale = staleAccountNames(names, runId);
  if (stale.length) {
    for (const n of stale) await page.getByRole("checkbox", { name: new RegExp(n) }).check();
    await page.getByRole("button", { name: /delete/i }).click();
    await page.getByRole("dialog").getByRole("button", { name: /delete/i }).click();
  }
  await importCsv(page, fixtureCsv(runId, { csm: env.users.csm.email, am: env.users.am.email }));
  return { deleted: stale.length, imported: 15 };
}
```

```js
// QA agent entry point. Order is load-bearing: pre-flight and the org guard both run
// before reset, because reset is the first thing that writes.
import { mkdirSync, writeFileSync, readFileSync, existsSync, readdirSync } from "node:fs";
import { execFileSync } from "node:child_process";
import { chromium } from "playwright";
import { loadQaEnv } from "./env.mjs";
import { makeRunId, runScenarios, summarise, GuardError } from "./core.mjs";
import { parseLiveVersion, checkVersion } from "./guard.mjs";
import { signIn } from "./session.mjs";
import { resetQaOrg } from "./reset.mjs";

const args = process.argv.slice(2);
const feature = args.includes("--feature") ? args[args.indexOf("--feature") + 1] : null;
const skipReset = args.includes("--skip-reset");
const OUT = new URL("./out/", import.meta.url);

const env = loadQaEnv();
const runId = makeRunId();
const dir = new URL(`${runId}/`, OUT); mkdirSync(dir, { recursive: true });
const startedAt = new Date().toISOString();
const notes = [];

execFileSync("git", ["fetch", "-q", "origin", "master"]);
const masterVersion = execFileSync("git", ["rev-parse", "--short", "origin/master"]).toString().trim();
const res = await fetch(env.baseUrl, { cache: "no-store" }).catch(e => ({ ok: false, statusText: e.message }));
if (!res.ok) { console.error(`pre-flight: ${env.baseUrl} unreachable (${res.status ?? ""} ${res.statusText})`); process.exit(3); }
const liveVersion = parseLiveVersion(await res.text());
const v = checkVersion(liveVersion, masterVersion);
if (!v.ok) { console.error(`pre-flight: ${v.message}`); process.exit(3); }

const featDir = new URL("./features/", import.meta.url);
const files = readdirSync(featDir).filter(f => f.endsWith(".mjs") && (!feature || f.startsWith(feature))).sort();
if (!files.length) { console.error(`no feature matches "${feature}"`); process.exit(3); }
const scenarios = (await Promise.all(files.map(f => import(new URL(f, featDir))))).flatMap(m => m.scenarios);

const browser = await chromium.launch({ channel: process.env.CRM_TEST_CHANNEL ?? "msedge" });
let code = 0, results = [];
try {
  if (!skipReset) {
    const admin = await signIn(browser, env, "admin");
    try { const r = await resetQaOrg({ ...admin, runId }, runId); notes.push(`reset: deleted ${r.deleted} stale QA accounts, imported ${r.imported}`); }
    finally { await admin.close(); }
  }
  results = await runScenarios(scenarios,
    async s => ({ ...(await signIn(browser, env, s.role ?? "admin", s.viewport ? { viewport: s.viewport } : {})), runId }),
    { onFail: async (s, ctx) => {
        if (!ctx?.page) return undefined;
        const file = `${s.id.replaceAll("/", "__")}.png`;
        await ctx.page.screenshot({ path: new URL(file, dir), fullPage: true });
        return { screenshot: file };
      } });
  code = results.some(r => r.status === "fail") ? 1 : 0;
} catch (e) {
  if (!(e instanceof GuardError)) throw e;
  console.error(e.message); code = 2; notes.push(e.message);
} finally { await browser.close(); }

notes.push("Add-user scenario leaves one unconfirmed sign-up per run (qa+<runId>@mail.onevio.in).");
const summary = summarise(results);
const out = { runId, startedAt, finishedAt: new Date().toISOString(), liveVersion, masterVersion, feature, summary, results, notes };
writeFileSync(new URL("results.json", dir), JSON.stringify(out, null, 2));
const histFile = new URL("history.json", OUT);
const history = existsSync(histFile) ? JSON.parse(readFileSync(histFile, "utf8")) : [];
history.push({ runId, summary, liveVersion, failedIds: results.filter(r => r.status === "fail").map(r => r.id) });
writeFileSync(histFile, JSON.stringify(history.slice(-20), null, 2));
console.log(`${runId}: ${summary.pass} pass, ${summary.flaky} flaky, ${summary.fail} fail -> ${new URL("results.json", dir).pathname}`);
process.exit(code);
```

Because `run.mjs` is under `tests/`, `import "playwright"` resolves from `tests/node_modules`. Verify with `node tests/qa/run.mjs --feature 99-none` → exits 3 with `no feature matches` (after pre-flight passes) — that proves imports resolve and pre-flight works live.
